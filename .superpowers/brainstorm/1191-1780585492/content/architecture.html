Architecture — how the pieces fit

Section 1 of 4. Details in the terminal; here's the shape of it.

ELECTRON RENDERER (UI)
  Sidebar (projects + terminals + status badges)
  Terminal panes — xterm.js
    │   ▲
  keystrokes │   │ output + status
    ▼   │  (IPC)
ELECTRON MAIN (Node)
  • PTY Manager — node-pty, one ConPTY per terminal
    ↳ spawns shell in project folder, auto-runs `claude`
    ↳ injects ARW_TERMINAL_ID + ARW_EVENT_URL into env
  • Status Bridge — tiny local HTTP server (127.0.0.1)
    ↳ receives hook events, maps to terminal, updates state
  • Store — projects + layout saved to disk (JSON)
    ↳ ▲
CLAUDE CODE HOOKS (configured once by the app)
  Notification→needs-you · Stop→idle · PreToolUse→working
  each hook POSTs {id, state} to ARW_EVENT_URL ──────┘

Key idea: status comes from Claude Code's own hooks, not from guessing by scraping terminal text. Reliable and future-proof.
