Which agent states should the sidebar show?

These are the badges/colors that would appear next to each terminal so you know who needs you. Question is in the terminal — here's what each could look like.

🟢 Working — Claude is actively generating / running tools
🟡 Needs you — waiting on a permission prompt or a question (blocked!)
⚪ Idle / done — finished its turn, waiting for your next prompt
🔴 Error / exited — the process crashed or the command failed
🔵 Unread output — produced output since you last looked at this tab
