Tech stack — three ways to build it

All three embed real Windows terminals (ConPTY) running `claude`. They differ in language, weight, and ecosystem.

A · Electron + xterm.js + node-pty ★ rec

The exact stack VS Code's terminal uses.

Pros

Proven terminal rendering · rock-solid ConPTY support · huge ecosystem · fast to build · easy hook/IPC watching in Node

Cons

Heavier install (~150MB) · higher RAM

B · Tauri (Rust) + xterm.js

Web UI, Rust backend, portable-pty crate.

Pros

Tiny binary (~10MB) · low RAM · modern · same xterm.js rendering

Cons

Write Rust for PTY/IPC · smaller ecosystem · more setup friction

C · .NET WPF / WinUI (native)

Pure Windows-native, no web layer.

Pros

Native feel · smallest footprint · no Chromium

Cons

Terminal emulation is the hard part — fewer mature controls than xterm.js · most custom work

My recommendation: A — Electron. It's the shortest path to a reliable terminal on Windows, and the status-via-hooks piece is trivial in Node.
